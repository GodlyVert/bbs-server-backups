Private backups,
stored in your Drive.

BBS Server Backups helps its owner keep encrypted copies of data from a privately operated server in the owner's Google Drive account.

How it works

  1. The owner authorizes the backup application to use Google Drive.
  2. Restic encrypts backup contents and file names before upload. Rclone transfers the encrypted repository to Drive.
  3. The owner configures daily scheduled backups, retention, and recovery checks on the private server.

This is a personal backup utility, not a public file-sharing or cloud storage service. These pages provide application and privacy information; backups and Google authorization do not run on this website.

Limited Google Drive access

The application requests the drive.file permission to create and manage backup files created by the application. It does not request broad access to every file in the owner's Drive.

OAuth credentials are stored privately on the owner's server. They are not embedded in this website or its public source files.

The owner stays in control

The owner controls the backup schedule, encryption credentials, and retention policy, and can revoke Google access at any time. Revoking access stops future authorized access; it does not delete existing backups.

Read the privacy policy for details about data use, retention, and deletion.

Contact

For application or privacy questions, use the project's GitHub issue tracker. Issues are public. Do not include backup contents, tokens, encryption keys, or other confidential information.
